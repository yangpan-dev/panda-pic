# 熊猫图库：下载与安装

普通用户可以直接下载已经编译好的应用，不需要安装 Xcode、Swift 或运行构建命令。

## 系统要求

- macOS 14（Sonoma）或更新版本。
- Apple Silicon（M 系列）或 Intel Mac，使用同一个 Universal 通用安装包。
- 可通过「苹果菜单 → 关于本机」查看系统版本与芯片信息。

当前版本 **1.1.1** 使用本地 ad-hoc 签名，**尚未使用 Apple Developer ID 签名或经过 Apple 公证**。从浏览器下载后，首次打开可能需要按下文通过系统的「仍要打开」确认。

## 1. 下载

打开 [最新版本下载页](https://github.com/yangpan-dev/panda-pic/releases/latest)，在 **Assets** 中选择：

| 文件 | 用途 |
| --- | --- |
| [PandaGallery-macOS-universal.dmg](https://github.com/yangpan-dev/panda-pic/releases/latest/download/PandaGallery-macOS-universal.dmg) | 推荐：打开磁盘映像，拖动安装 |
| [PandaGallery-macOS-universal.zip](https://github.com/yangpan-dev/panda-pic/releases/latest/download/PandaGallery-macOS-universal.zip) | 备用：解压后拖入「应用程序」 |
| SHA256SUMS.txt | 下载包的 SHA-256 校验值 |
| INSTALL-zh-CN.md | 可单独下载保存的本教程 |

## 2. 安装

### DMG 安装（推荐）

1. 双击下载的 `PandaGallery-macOS-universal.dmg`。
2. 在打开的窗口中，将 **熊猫图库.app** 拖到 **Applications（应用程序）** 文件夹。
3. 等待复制完成，在 Finder 侧栏将「熊猫图库」磁盘映像推出。
4. 打开「应用程序」，双击 **熊猫图库**。

如果没有管理员权限，也可把应用拖入自己的 `~/Applications` 文件夹后打开。

### ZIP 安装

1. 双击 `PandaGallery-macOS-universal.zip` 解压。
2. 将解压得到的 **熊猫图库.app** 拖入「应用程序」。
3. 从「应用程序」打开熊猫图库。

请先把应用复制到「应用程序」，再从那里运行，便于之后更新。

## 3. 第一次打开

如果 macOS 显示“无法验证开发者”或“Apple 无法检查是不是包含恶意软件”，在确认安装包来自本仓库且校验无误后：

1. 先尝试打开一次熊猫图库，然后关闭该提醒。
2. 打开 **系统设置 → 隐私与安全性**。
3. 滚动到「安全性」，找到关于熊猫图库的提醒，点击 **仍要打开**。
4. 根据系统提示验证身份，再点击 **打开**。

这是针对本应用的一次确认。后续通常可直接双击运行。具体入口和是否可用取决于 macOS 版本及设备管理策略，详见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

如果系统明确提示应用已损坏或将损坏电脑，请先核对校验值、重新下载安装包，仍有问题时在仓库提交 Issue。不要关闭整个系统的安全检查。

## 4. 开始看图

1. 打开软件后点击 **打开**，或按 `⌘O` 选择一张图片，也可以将图片拖入窗口。
2. 程序会自动发现这张图片所在目录的其他图片，**无需另选文件夹**。
3. 按 `←` / `→` 切换上一张、下一张；双击缩略图进入大图，按 `Esc` 回到图库。
4. 点击 **编辑** 可裁剪、旋转、翻转、调节亮度与色彩；完成后选择 **导出** 保存副本。原图会保留。

从 Finder 打开图片：右键图片 →「打开方式」→「熊猫图库」。首次未出现在列表中时，可点「其他」并在「应用程序」中选择熊猫图库。

要设为某类图片的默认应用：在 Finder 选中该类图片 → 按 `⌘I` →「打开方式」选择熊猫图库 →「全部更改」。

## 5. 常用设置

- 按 `⌘,` 或点击左下角「设置」。
- **白天 / 黑夜**：默认白天，手动选择会保存。
- **缩略图大小**：小 / 中 / 大，默认中。
- **显示图片名称**、**底部缩略图**、**幻灯片间隔**与**循环播放**也在设置中。
- 排序、格式筛选和图片信息可从右上角「…」进入。

## 6. 文件访问权限

当系统询问是否允许访问「桌面」「文稿」或「下载」时，只需允许你准备浏览的图片所在位置。

如果能打开当前图片却无法切换同目录其他图片，可检查 **系统设置 → 隐私与安全性 → 文件与文件夹 → 熊猫图库**，允许相应位置，然后重新打开图片。受设备管理、磁盘或文件自身权限限制时，需要相应权限才能枚举目录。

## 7. 更新与卸载

**更新：** 退出正在运行的熊猫图库，下载最新 DMG 或 ZIP，用新应用替换「应用程序」中的旧应用。收藏、相册与偏好设置会保留。当前没有自动更新功能，需要手动下载新版本。

**卸载：** 退出应用后，将「应用程序」中的熊猫图库移入废纸篓。原始图片和导出文件不会因此删除。

相册保存的是图片路径；如果在其他软件中移动或改名，需要重新打开对应图片。

## 8. 可选：校验下载文件

在 Release 页面同时下载 `SHA256SUMS.txt`，然后在终端中执行：

```sh
cd ~/Downloads
shasum -a 256 PandaGallery-macOS-universal.dmg
```

将输出的 64 位校验值与 `SHA256SUMS.txt` 中 DMG 对应的一行比较。ZIP 也可以用相同方法校验。如果两个下载包都在当前目录，可执行 `shasum -a 256 -c SHA256SUMS.txt` 检查两者。
