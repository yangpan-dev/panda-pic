# 熊猫图库 1.1.1

macOS 原生图片浏览与轻量编辑工具，下载安装包后即可使用，无需开发环境。

## 下载与安装

- **推荐：** `PandaGallery-macOS-universal.dmg`，打开后将熊猫图库拖到 Applications。
- **备用：** `PandaGallery-macOS-universal.zip`，解压后将应用拖入「应用程序」。
- 系统要求：macOS 14+，Universal 包包含 Apple Silicon 与 Intel 两种架构；Apple Silicon 已实机验证，Intel 尚未实机测试。
- [完整中文下载安装教程](https://github.com/yangpan-dev/panda-pic/blob/v1.1.1/docs/INSTALL.md)。教程和 `SHA256SUMS.txt` 也随本 Release 提供。

## 功能

- 打开一张图片后自动发现同目录图片，左右键即可切换，无需另选文件夹。
- 简洁白天 / 黑夜主题，默认白天；偏好设置会保存。
- 缩略图小 / 中 / 大三档，默认中；界面字号统一增加 2pt。
- 缩放、平移、全屏、收藏、相册、搜索和幻灯片。
- 比例裁剪、旋转翻转、亮度与色彩调整、滤镜、撤销重做、原图对比。
- PNG / JPEG / TIFF / HEIC 导出副本，保留原始图片。

## 首次打开

本版本为 ad-hoc 签名，**尚未经过 Apple Developer ID 签名及 Apple 公证**。如果 macOS 提示无法验证开发者，在确认来源并校验文件后，先尝试打开一次，再前往 **系统设置 → 隐私与安全性 → 仍要打开**。具体说明见教程及 [Apple 官方文档](https://support.apple.com/zh-cn/102445)。

9 项自动测试覆盖同目录发现、自然排序、导航、裁剪、图像处理、原图保护、EXIF 方向与主题偏好。GIF 当前以首帧显示；目录在打开图片时扫描，不实时监听外部文件变动。
